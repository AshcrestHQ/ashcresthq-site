# Changelog

All notable changes to the **AshcrestHQ Website** project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

---

## [1.0.0] - 2026-08-23

### Added
- **Official Production Web Presence**: Complete rewrite and launch of the AshcrestHQ flagship portal.
- **Projects Arsenal (`/projects`)**: Dynamic showcase of flagship projects (**Janus**, **Aegis**, **Holocron**) with real-time GitHub timestamp fetching.
- **Dedicated Project Subpages**: Full documentation routes for Aegis moderation bot (`/aegis`, `/aegis/privacy`, `/aegis/terms`).
- **Cloudflare Pages CI/CD Pipeline**: GitHub Actions workflow (`ci.yml`) for automated linting, building, and static export deployment.
- **Open Source Governance Suite**: Added `CONTRIBUTING.md`, `CODE_OF_CONDUCT.md`, `LICENSE` (MIT), and GitHub Issue Templates.
- **UI Design System**: Built with Next.js 16 (App Router), Tailwind CSS v4, Framer Motion staggered entry animations, and organic glassmorphic components.

### Changed
- Replaced temporary placeholder documentation with complete AshcrestHQ organization breakdown and deployment architecture guide.
