route The Development Orbit

Phase 01

call_split Fork & Clone

Create your own independent copy of the repository to begin charting your course without affecting the main telemetry.

$ git clone https://github.com/ashcrest/core.git
$ cd core
Phase 02

build Build & Test

Initialize the local environment. Ensure all thrusters are nominal by running the comprehensive test suite locally.

$ pnpm install
$ pnpm test --watch
Phase 03

merge Pull Request

Submit your trajectory adjustments back to central command. Ensure your PR description clearly outlines the modifications.

$ git checkout -b feat/new-module
$ gh pr create
